# Номерная — генератор номеров

Локальная доработка существующей статической веб-версии. Это по-прежнему один HTML-файл без сборщика, серверной части, PWA-манифеста или Android-проекта. Публичную страницу на GitHub Pages эта папка не меняет.

## Что изменено

- Для обычных комбинаций добавлены конкретное короткое название и объяснение вместо общего «Случайное сочетание»; старые сохранённые записи с прежним текстом тоже получают читаемое описание в интерфейсе.
- В выбор региона добавлены режим «Все регионы» и расширенный список кодов России. В режиме всех регионов код выбирается случайно из списка допустимых значений. Видеореференс и исходный продукт не давали спецификации выбора Беларуси или других типов табличек, поэтому такие режимы не добавлялись.
- Повторные нажатия во время анимации/пропуска защищены короткой блокировкой, чтобы не списывать стоимость несколько раз за один быстрый тап-бёрст.
- Новый профиль начинается с 0 игровых рублей и быстрой скорости. Если баланса не хватает на выбранный тариф, генерация бесплатна; при достаточном балансе обычная стоимость списывается штатно. Баланс не уходит в минус.
- При стоимости результата от 1 000 000 игровых рублей включается отдельное плавное раскрытие: более длинная прокрутка, анимированный счётчик и мягкое золотое свечение. Уменьшение движения и отключение анимации по-прежнему соблюдаются.
- Чистые старые профили без истории мигрируют со стартовых 25 млн на 0; сохранённый прогресс и уже использованный баланс не сбрасываются.
- Добавлены воспроизводимые QA-скрипт и отчёт; тестовый режим не внедрён в пользовательский интерфейс.

Существующие разделы и настройки сохранены: генератор, коллекция, сейф/избранное, каталог редкостей и серий, статистика, настройки генерации, общие настройки, экспорт/импорт и подтверждение сброса, локальное сохранение, темы, звук/громкость, скорость и качество эффектов. См. [`QA_REPORT.md`](QA_REPORT.md) и [`qa/requirement-register.csv`](qa/requirement-register.csv).

## Запуск

Откройте `index.html` в современном браузере. Для локального HTTP-сервера из корня проекта:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## QA

- Вероятности и валидность выходов (500 000 образцов): `node qa/rarity-check.mjs`.
- Представительные сценарии интерфейса (Playwright и Chromium должны быть установлены): `node qa/browser-qa.mjs`.
- Нулевой баланс, миграция сохранений и анимация результата ≥1 млн: `node qa/behavior-qa.mjs`.
- Реестр из исходного задания: ровно 5 000 строк с исходным текстом каждого требования, статусом наличия функции и честным статусом проверки.

## Ограничения выпуска

Проект остаётся веб-сайтом. Он не является Android APK/AAB и не опубликован в RuStore. Публикация требует Android-сборки, подписи, карточки и подтверждений владельца; требования и незакрытые задачи перечислены в отчёте. Не загружайте keystore или секреты в репозиторий.


**Публикация:** эти локальные изменения пока не отправлены в GitHub; для обновления `-v2` потребуется вход/авторизация владельца репозитория.
